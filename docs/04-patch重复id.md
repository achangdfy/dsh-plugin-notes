# 04 · 启动崩溃：duplicate loader entry id

## 现象

改完 `cordis.patch.yml`，重启，DSH 起不来了。日志里一句：

```
duplicate loader entry id: xxx
```

## 为什么会重复

这个文件是**追加式**的：`- insert:` 一段一段往里塞。你装一次插件，多一段；再装一次（或者自己手写了一遍），就多一段同样的 id。

长得一模一样的两个条目，加载器不知道你要哪个，直接拒。

## 怎么修

打开 `~/.dsh/profiles/<你的 profile>/cordis.patch.yml`，同一个 `id:` 只留**最后一条**，前面的删掉。

改之前先复制一份备份——文件名改成 `cordis.patch.yml.bak-日期` 就行。启动崩了的时候，你没有界面可用，只能靠它救。

用注入器的话，有个现成的检查：先跑一次「只查不写」的修复，看它要动哪几条，确认没问题再让它写。

## 别做的事

- 别为了省事把整个文件清空。里面可能还有别人的装配（别的插件、别的 patch），清掉就一起没了。
- 别在崩溃状态下反复重启碰运气。它就是每次都崩，跟你重启几次无关。

## 一句教训

**patch 文件是纯文本，但它是启动链上的一环。** 改它之前拷贝一份，比什么都省心。
